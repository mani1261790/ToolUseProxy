## 作業時の注意

- repository rootの`protected_sources.json`はToolUseProxyが作成した利用者管理ファイルである。削除、編集、commitをしない
- protected source本文、raw Hook payload、URL、host、absolute pathをIssueやCI artifactへ出さない
- semantic-only、LLM verdict、unknown classificationを自動allowへ昇格しない
- Hookへ届かないHosted Web Search、`write_stdin`継続、未検証nested toolを保護済みと表現しない
- unknownにprotected flowがある場合のfail-closedを維持し、検出精度改善で既存blockを弱めない
