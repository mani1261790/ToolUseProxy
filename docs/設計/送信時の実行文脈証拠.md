# 送信時の実行文脈を観測する

2026-09-24。実装・検証中。alpha.13への配布済み変更ではない。

## 解決する問題

送信対象はToolCallの文字列だけでなく、既定値や設定で変わる。
alpha.13の実Hookでは、リポジトリ内の設定だけを渡したため、継承された設定の不足を
モデルが指摘し、履歴を追加して何度も再判定していた。これは情報の由来を調べる問題とは別である。

## 共通契約

コントローラーが固定した読取り専用アダプターで、操作に必要な現在の設定を観測する。
モデルが任意コマンドを要求する仕組みにはしない。観測結果は以下を持つ。

- 契約版、アダプター版、ToolCall入力・cwd・workspaceへの結び付け。
- 観測の成否と範囲。失敗を「設定なし」に変換しない。
- 順序や重複を保持した事実。値を取得しただけでは送信対象や秘密由来と確定しない。
- 同じアダプターによる送信直前の再観測。変更があれば以前の解決結果を使わない。

設定の観測結果を送信対象解決のキャッシュ鍵へ含める。対象の内容版と保護登録は別に再確認する。
設定由来の送信文字列を指定するときは、モデルに値を再生成させず、観測済みfactsへの
JSON pointerとバイト範囲を使う。任意の説明文・未観測値は参照できない。

これは送信許可のキャッシュではない。意味依存の推定と現在の秘密情報源への探索は残す。

## 現在のアダプター

最初の実装は再現事例である単純な`git push`に接続した。送信自体は実行しない。
Gitの固定されたローカル設定照会と現在ブランチの照会のみを使い、出力サイズと実行時間を制限する。
system/global/local/worktree/継承されたコマンド設定のうち、送信先・ref選択に関連する項目を取得する。
資格情報ヘルパー、ネットワーク、ユーザーの実行スクリプトは呼び出さない。

include/includeIfはコントローラーが必要な設定項目をコピーし、そのコピー上でGitに条件と順序を
評価させる。元ファイルの再帰的な読込みをGitへ委譲しない。相対パスの基準と取得元を保持し、
禁止された制御ファイルは開かない。条件が成立した禁止参照のみ取得不能とし、不成立の参照は適用しない。
コピーの一時パスはキャッシュ鍵へ残さない。読込み数・出力量・実行時間には上限を設ける。
worktree gitfile、明示的なGit環境のリポジトリ切替、複合構文や`git -c`は取得契約の対象外。
これらを既定値や安全とみなしてはいけない。Hook環境に現れないshell起動処理の設定変更は観測できない。

## 確認したことと残件

単体検証は、global設定だけの変更、環境設定による上書き、現在ブランチ変更、呼出し変更、
取得不能と既定値の区別、禁止された制御ファイルを開く前の拒否、観測値の参照範囲、
解決結果の送信前失効、同じ設定での解決計画の再利用を対象にする。
この変更を含む全体テストは310 passed / 1 skipped。変更箇所のRuffとgit diff --checkも通過。
通常のGitとの比較で、入れ子・順序・重複値・改行・値なしの真偽設定、onbranch、gitdir、
gitdir/i、hasconfig条件を確認した。読み込まれるファイルの変更や新設は再解決を要求する。

実リハーサルの記録を隔離DBへ複製した実モデル再生では、送信対象特定の初回が14.565秒・
モデル1回、2回目が0.269秒・モデル0回。両方coverage=complete。外部送信は実行していない。
これは送信対象の解決段階だけであり、グラフ判定全体やDesktop Hookの待ち時間ではない。
include対応後の再試験でも初回15.071秒・モデル1回、2回目0.301秒・モデル0回で完了した。

### 設定値の由来

Gitの[show-origin](https://git-scm.com/docs/git-config#Documentation/git-config.txt---show-origin)で
取得元ファイルを観測し、送信値をその資源の生成元へ接続した。モデルが設定読取りを
返さなくてもコントローラーが関係を保持する。設定元が後から保護登録された場合も再推定せず遮断する。

同じ設定ファイルの全項目を一括で継承させない。項目名・観測値・送信するバイト範囲を
projectionとして生成元の解析へ渡す。別途そのファイル全体も送信対象なら、この限定を適用しない。
意味判定契約はproperty-flow-v16。機械的な取得元の接続と、変換の意味推定は別である。

実モデルの合成記録試験では、同じ設定ファイル内の公開宛先は22.493秒でallow、秘密メモの
設計値を反映した宛先は28.746秒でprotected_source_reachableとなった。送信は実行していない。
対象設定値を試験側が指定し、その由来を実モデルに判定させた試験であり、push全体の検査ではない。
単体試験では、取得元をモデルが省略した場合・混在した別項目・後からの登録も確認した。

alpha.14候補として配布・インストール確認と、原文・派生物・独立した案内の実Hook試験を行う。
Ask for approvalでの収録手順も未確認。これらが終わるまで収録可能とは報告しない。
