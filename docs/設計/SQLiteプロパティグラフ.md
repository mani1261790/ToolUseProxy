# SQLiteによるプロパティグラフ

[文書一覧](../索引.md) · [エッジ生成と送信判定](エッジ生成と送信判定.md)

原記録とグラフは同じ `events.db` の別テーブルに保存します。外部のグラフDBは使いません。以下はv0.2.0-alpha.16の構造です。

## 操作と資源の区別

ToolCallをノードとし、実行前の入力と実行後の出力をIDで対応付けます。ノードには、判定した読取り・書込みの対象とその理由を持たせます。これらの属性はモデルや操作契約から得るもので、OSレベルの全アクセス記録ではありません。

ファイルの版や生成元の観測は別の台帳に保持します。実行前後で確認できた資源の同一性、成功した書込み、Gitの不変な内容などを使います。パスが同じという理由だけで、古い内容と新しい内容を同一視しません。

## 主なテーブル

| テーブル | 保存するもの |
| --- | --- |
| `events` | Hookから届いた原記録 |
| `semantic_flow_nodes` / `semantic_flow_decisions` | 操作ノードの識別と、ログ画面でも使う判定結果 |
| `graph_revisions` | 観測、モデル、プロンプト版、判断根拠に対応する判定版 |
| `graph_heads` | プロジェクト・セッション別の各ノードの現在版 |
| `graph_edges` | 判定版ごとの有向依存エッジと理由。入辺・出辺の索引を持つ |
| `graph_accesses` | 読取り・書込みの対象パスと理由。パス検索用の索引を持つ |
| `graph_revision_links` | その判定が参照した親の判定版 |
| `graph_output_selections` / `graph_resource_selections` | 解析対象にした出力断片やファイルの版 |
| `graph_completed_reviews` / `graph_review_parts` | 完了済み判定と、分割した判定の再利用情報 |
| `graph_policies` / `graph_policy_checks` | 判定時の保護指定と、その指定に対する結果 |
| `graph_progress` | 解析中・完了・未完了の進捗 |
| `flow_operation_plans` / `flow_file_observations` / `flow_immutable_reads` | 予定した資源操作、実行前後の観測、不変な内容の読取り |

## 保護指定を来歴から分ける

意味依存のモデルに保護一覧を渡して「秘密か」を決めさせることはしません。現在登録されているファイルと、記録された読取り属性を機械的に照合して保護経路の起点を作ります。最後に送信ノードから入辺を逆向きに幅優先探索します。

保護指定を追加した場合は、記録開始後の既存の経路にも反映できます。登録変更だけで意味エッジを推定し直す必要はありません。不足する来歴は送信時などに解析し、登録操作の一部として本文を読んだりモデルを起動したりはしません。

通常の登録範囲はファイル全体です。内容版は同一性と由来の確認に使うもので、ある時点で登録した本文だけを保護する指定ではありません。未対応の範囲指定や曖昧な同定を、完了した検査として扱いません。

## 判定版と再利用

親ノードの現在版だけでなく、判断時に参照した版を保存します。出力断片や特定のファイルだけに絞った判定を、操作全体の判定で上書きしません。複数の断片を使う場合は必要範囲をまとめて扱います。

モデル・プロンプト版・履歴・対象範囲が一致し、必要な証拠を再確認できるときに完了済みの判定を再利用します。履歴の連鎖ハッシュにより、同じ履歴全文の繰り返しのハッシュ計算を減らします。古い「許可」を現在の保護指定にそのまま流用するキャッシュではありません。

## 同時処理と上限

同一セッションのグラフ更新は直列化します。モデルの応答を待つ間はDBの書込みトランザクションを保持しません。最後の保護指定の取得・探索・判定保存は短い書込みトランザクションで確定します。

原記録の取得、分割したモデル入力、再帰的な由来の展開、経路探索には上限があります。上限を超えた履歴を黙って捨てて許可することはありません。具体的な処理順と現行上限は[アルゴリズム](エッジ生成と送信判定.md)、未完了時の挙動は[復旧設計](判定完了と復旧.md)を参照してください。

この保存構造だけで、大規模な実利用や任意のモデル応答を処理しきれると保証するものではありません。旧ベンチマーク、初期の上限、廃止した障害時方針の経緯は[初期実装の記録](../history/v0.2/SQLiteプロパティグラフ初期実装.md)に残しています。
