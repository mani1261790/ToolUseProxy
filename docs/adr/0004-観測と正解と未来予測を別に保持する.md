# 観測と正解と未来予測を別に保持する

既存の情報流グラフは観測した構造と推定した対応を含むため、そのまま将来予測の正解にすると検出器の誤りを再生産する。観測時点を固定した入力、独立した根拠による正解、検出器の推定、未実行の未来予測を別に保持し、同じ操作・情報物の識別子で対応付ける案とする。単一グラフへ集約する簡潔さより、学習への未来情報の混入防止と、予測した経路を実際に起きた経路と誤認しないことを優先する。

正解が不明な経路は不明として残し、別のLLMによる推定だけで確定しない。対象と確認事項は[実装計画](../運用/自動攻防試験と将来経路予測の実装計画.md)を参照する。
