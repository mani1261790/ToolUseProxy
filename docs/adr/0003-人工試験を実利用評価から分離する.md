# 人工試験を実利用評価から分離する

自動探索では同種の攻撃を意図的に繰り返し、再現のために人工的な操作本文も必要になるため、内容非保持の実利用評価へ統合すると、通常利用の件数と精度の意味を失う。人工試験は専用の保存形式・保存先・改善提案入口を持ち、既存のIssue同期では内容検査と重複防止の部分だけを共用する案とする。保存・移行処理は増えるが、人工試験の成功を実利用の安全性と取り違えず、実情報を研究用の原文記録へ混入させないことを優先する。

対象と確認事項は[実装計画](../運用/自動攻防試験と将来経路予測の実装計画.md)を参照する。
