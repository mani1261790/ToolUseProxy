# 旧版の保管場所

現行製品は `tooluseproxy/engine/` と `tooluseproxy/app.py` です。
このディレクトリは通常起動・プラグイン・wheel・sdistに含めません。

- `v0.1/hook_monitor/`：旧I/O比較・解析エンジン。旧DB互換性試験でも使用します。
- `v0.1/tooluseproxy/`：旧CLI・予測・管理ツール。現行実装との混用はしないでください。
- `v0.1/tests-and-tools.tar.gz`：旧テストと旧スクリプト。ファイル別のSHA-256を隣に保存しています。
- 旧文書：`docs/history/v0.1/`。

今回の移動前の正確な状態はコミット `fcbaecfbb1917f1a80dd687b640e82cea15f9e1f`、
旧製品の公開版はタグ `v0.1.0-alpha.25` で再現できます。復元は現在の作業ツリーに上書きせず、
別のworktreeを使います。

```sh
git worktree add --detach /tmp/tooluseproxy-v1-history v0.1.0-alpha.25
```

圧縮物は元の相対パスを保持しています。内容を調べる場合は一時ディレクトリへ展開してください。
移動前の修正を含む旧テストを再現する場合は、上記コミットの別worktreeを使用します。
現行版で旧テストを通すことは目的にしていません。

圧縮はチェックアウト上の容量とファイル数を減らすためです。過去のGit履歴は削除・書換えしていないので、
既存の `.git` 容量がその分減るわけではありません。ルートのユーザー管理データも対象外です。
